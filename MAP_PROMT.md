# MAP_PROMT.md — контракт CoreLink.Maps → CoreLink.Rx

**Актуализировано:** 10.11.2026  
**Статус:** managed Rx-карта и выбор единиц реализованы, собраны и интеграционно испытаны для штатных и неизвестных значений Measurme. Дополнительная зарегистрированная система ещё не испытывалась.

## 1. Единый источник данных

`CoreLink.Maps` формирует **две проекции одной физической карты**: бинарную `CoreMap` v2 для Core и managed `RxMapConfiguration` для Rx. Изменять бинарный формат ради единиц нельзя. `MapProvider` предоставляет обе проекции через `IMapProvider.TryLoad` и `TryLoadRxMap`.

Порядок `PhysicalRegister[]` в `RegisterMap` определяет `ValueId == index`. Адрес Modbus не является ValueId. Одна Float32 занимает два регистра и одно декодированное значение. `mapId` в текущем статическом `MapProvider` не выбирает альтернативную карту — не приписывать ему поддержку произвольных конфигураций.

## 2. Реальный API единиц

Вместо старых `enum UA/EU` используется масштабируемый формат:
- `RegisterMap.SupportedUnitSystemIds` — зарегистрированные **положительные** идентификаторы систем; сейчас `[1, 2]`.
- `UnitEntry(int SystemId, string Symbol)` — символ конкретного параметра для конкретной системы.
- `Units(params UnitEntry[] entries)` — описание единиц в `PhysicalRegister`. Отсутствие `Units` означает отсутствие символов.
- `UnitSymbols` — технические строковые обозначения (psi, bar, MPa и т. п.). Никакого коэффициентного пересчёта.
- `RxMapValue(Name, IReadOnlyDictionary<int,string> Units)` и `RxMapConfiguration` с `Values`, `SupportedUnitSystemIds`, `UnitSystemValueId`, `RxIntervalMs`.

Пример текущего описания:

```csharp
public static readonly int[] SupportedUnitSystemIds = [1, 2];
new("Pressure_1", 7, RegisterType.Float,
    new Units(new UnitEntry(1, UnitSymbols.Psi),
              new UnitEntry(2, UnitSymbols.Bar)))
```

**Для новой системы** зарегистрировать положительный ID в `SupportedUnitSystemIds`, затем добавить `UnitEntry` у требуемых параметров. Отсутствие `UnitEntry` у параметра в *зарегистрированной* системе — штатное пустое обозначение. Нет фиксированных проверок `1 or 2` в Rx.

## 3. Валидация

`RxMapBuilder` и `RxDefinitionMapper` проверяют конфигурацию **один раз до запуска**: пустые/повторяющиеся имена, неверный `RxIntervalMs`, отсутствующий или повторяющийся ID, ID ≤ 0, единица для незарегистрированной системы, пустой символ в явно заданной записи и выход `UnitSystemValueId` за диапазон. Если `Measurme` отсутствует, default ID 1 должен быть зарегистрирован. При ошибке карту отклонить, а не игнорировать некорректную запись.

`RxValueDefinition` хранит `IReadOnlyDictionary<int,string>`; запись данных выполняется по ValueId без поиска имени в каждом цикле.

## 4. Семантика PLC Measurme

Техническое имя регистра — **строго `Measurme`** (написание намеренное). Его адрес в Modbus не фиксируется; позиция в `RegisterMap` определяет `UnitSystemValueId`. В текущем тесте это `ValueId=8`, адрес 0.

| Measurme | Поведение Rx | Диагностика |
| --- | --- | --- |
| 0 | Число и пустая единица | Нет ошибки |
| Зарегистрированный ID > 0 | Обозначение из словаря параметра или пусто, если запись отсутствует | Нет ошибки |
| Неизвестный/нецелый/недопустимый ID | Число и `—` для всех значений | Ошибка при новой причине |
| Нет регистра в карте | Система 1 по умолчанию | Нет ошибки |
| Ошибка → известный ID или 0 | Возвращение обычных обозначений | Сообщение восстановления |

Не подставлять единицы UA вместо некорректного `Measurme`. Не переводить значения между psi, bar, MPa: PLC уже возвращает числовое значение в выбранной им системе. Переводы текста интерфейса принадлежат Avalonia.

При `NoData` до первого успешного snapshot валидных измерений нет; при потере связи сохранённые измерения нельзя выдавать за свежие. Не менять единицы на прочерки исключительно из-за disconnect.

## 5. Испытания и границы

10.11.2026 проверены переключения 0/1/2/3/5/8/9 на внешнем симуляторе, включая неизвестный → известный и неизвестный → неизвестный; 121/121 успешных запросов, 120 `Snapshot Ok`, 0 snapshot-ошибок. `Measurme=0` даёт пустую строку; 3/5/8/9 — прочерк.

**Не проверено:** фактическая запись `TraceError`/восстановления в постоянный журнал, зарегистрированная система 3, настоящий аппаратный PLC. Симулятор 0..9 — лишь инструмент задания значений; он **не регистрирует** системы в карте.

## 6. Инженерные ограничения

Не вводить отдельную `UnitsMap`, перевод по строковому имени, reflection, runtime DI, конверсию чисел или новый формат Core v2. Код — только по явному запросу; один полный файл за шаг либо все полные файлы разом по прямой просьбе. GitHub изменять только по указанию. Ошибки диагностировать без спама; недоступность `TraceListener` не считать доказанной работой production-логирования.
